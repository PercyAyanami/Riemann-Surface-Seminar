# 黎曼曲面讨论班规划

2026-10-09 更新。原版已保存在 archive/pre-xiong-2026-10-09/。

20 次讨论，每次 2 小时，每节课单独确定一位主讲人，参加者轮流承担报告。面向学过实分析和线性代数、复分析与抽象代数基础不齐的同学。固定主线：小平的必要复分析 → Donaldson 的曲面与微分形式 → Narasimhan 前十章；Forster 补细节与习题。

先看 [参加者网页](Schedule.html)、[逐次阅读安排](Schedule.md)、[打印版](Schedule.pdf)。

## 为什么调整

把 Riemann-Roch 放在局部函数与整体障碍的框架里，复分析学到能使用即可，时间转给拓扑、微分形式、层与线丛。环、模和交换代数作为局部工具，不再前置四次课。Narasimhan 为唯一核心教材；Forster 是辅助书，不另外开一条并行主线。

20 次是一轮目标进度。第 6、12、17 次后做检查：形式计算、上同调和对偶是否讲清。必要时拆成两次顺延到假期或下学期。全班完成 RR 在明确标准输入下的推导；有限性、局部 ∂bar 可解、Weyl 引理和对偶非退化性的较重分析证明列为第二轮。

## 组织与工作量

每周只读卡片指定主题，不要求整章通读。A/B 课前尝试，C-E 课后任选一题，F 自愿拓展；六题是本班自编或改编题，不冒称 Forster 原书题号。视频全为选看，每次至多选一种。主讲人提前三天发一页提纲，课后整理 1-3 页记录。

普通参加者建议课前阅读 60-90 分钟、A/B 尝试 30-45 分钟；基础不齐者另留时间。主讲需提前一周认领，遇到概念跨度大时先和发起人缩小范围，不靠压缩讨论赶进度。每次课单独选定一位主讲人，大家轮流参加报告。第 6、12、17 次做进度检查。
